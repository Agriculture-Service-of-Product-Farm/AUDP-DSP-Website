# AUDP-DSP Public Website

Minimal public-facing website for AUDP-DSP under Agriculture Service of Product Farm (ASPF).

## Security Properties

- Static HTML only (no external scripts, fonts, or resources)
- Strict Content-Security-Policy
- `X-Content-Type-Options: nosniff`
- `Referrer-Policy: no-referrer`
- `robots: noindex, nofollow, noarchive`
- No forms, no analytics, no trackers, no third-party content
- No technical details, algorithms, or internal information disclosed

## Deployment

Suitable for GitHub Pages. Enable Pages in repository Settings and set source to the main branch root.

Do not add technical documentation, code samples, or architecture details to this site.

Main source repository remains private.
